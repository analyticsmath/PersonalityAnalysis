## Scene contracts

Opening: photograph begins inside an offset frame. Main title sits on solid paper planes. Title and its action are clipped out before the next text appears. Photograph expands to the viewport, crop advances, flat tonal veil increases, then assessment copy enters. There is a reading hold. No title crossfade.

Dimensions: quiet, unpinned explanation. The photo has internal parallax; personality, interests and values are readable together. No sample response is laid over the hero.

Conditions: three photographs sequentially take the same stage through bottom-to-top masks. New copy travels with its own scene, with a hold between takeovers. Controls scroll to actual timeline positions. Reverse scroll reconstructs the same states.

Career: differently proportioned photographic planes, native horizontal browsing, links to the actual occupational explorer. Selection does not get overwritten by a timer.

Progress: user-controlled divider with a native range input. Context illustration is explicitly distinguished from personal assessment history.

Trust: original example and explanation are physically composed together. Methodology and rights controls remain accessible through their real routes.

Finale: original working photograph returns in a closer crop with one clear invitation.

Mobile: independently positioned hero photo, smaller text planes, native touch scrolling, native gallery scrolling. Reduced motion exposes the source explanation and every condition as ordinary readable blocks.

## Engineering ownership

GSAP owns scene animation. ScrollTrigger owns normalized progress. Lenis smooths desktop wheel input and shares GSAP's ticker; touch input remains native. All timelines, listeners and ticker callbacks are cleaned up on navigation. View Transition API owns measured media snapshots; unsupported/reduced-motion browsers navigate immediately. The destination receives focus. Navigation has an independent interruption safeguard.

## Validation boundaries

Build and tests establish engineering behavior, not an award score. Browser evidence must be reviewed separately. A successful desktop pass cannot be reported as a mobile or actual-device performance pass. Full photo-rights clearance and psychometric validation are outside a motion test.
