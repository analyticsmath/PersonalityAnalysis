# Personality Assessor — Design-to-Codex Package
## The Living Record

This package is the complete design pipeline from reference reset through Codex implementation authority.

## Read in this order

1. `valtum-creative-web-design-brain-reset-research.md`
   - Reference re-synthesis and corrected design reasoning.

2. `personality-assessor-new-creative-thesis-art-direction-storyboard.md`
   - Product-truth research, concept candidates, selected thesis: The Living Record.

3. `personality-assessor-high-fidelity-static-frame-specification.md`
   - Exact desktop/tablet/mobile frame geometry, crop ownership, typography, Evidence Strip, route worlds.

4. `personality-assessor-living-record-composition-boards.pdf`
   - Visual composition-board pack. These are deterministic layout boards using labelled production-media placeholders because the connected Figma account is View-only in this session. The exact production asset names and crop roles are shown; Codex must use the actual Evidence in Context media derivatives in the repository.

5. `personality-assessor-motion-interaction-architecture.md`
   - Lenis/GSAP/SVG/R3F ownership, product-native verbs, frame choreography, fast/reverse/reduced-motion behavior.

6. `personality-assessor-responsive-fallback-accessibility-spec.md`
   - Desktop/tablet/mobile modes, no-WebGL, reduced-motion, accessibility, geometry and performance contracts.

7. `personality-assessor-final-codex-implementation-brief.md`
   - FINAL implementation authority. Give this to Codex together with files 3, 5 and 6. Files 1 and 2 are research/background authority.

The current public implementation is not the design baseline.
