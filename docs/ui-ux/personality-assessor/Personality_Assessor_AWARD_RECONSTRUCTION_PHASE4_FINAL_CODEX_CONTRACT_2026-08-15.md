# 4. VERIFIED PRODUCT TRUTH — BINDING COPY RULES

## 4.1 Adaptive assessment

Current backend truth:
- base questionnaire target: **22 questions**;
- possible maximum: **26**;
- supplemental extension step: **4**;
- extension logic uses confidence/coverage conditions;
- first questions may cycle through MCQ, Likert, slider and text formats;
- AI-assisted CV/context extraction and adaptive question generation are part of the current pipeline.

Therefore public copy may say:
- questions adapt to professional context and assessment coverage;
- additional questions may be used when more evidence is needed.

Do **not** promise:
- that every user gets fewer questions;
- that “AI chooses the perfect question in real time” unless that specific behavior is verified;
- exact completion-time claims unless measured.

## 4.2 Scoring

The structured scoring orchestrator produces:
- Big Five;
- RIASEC;
- Work Values;
- Career Signals;
- score validity;
- evidence counts/sources;
- missing evidence/dimensions;
- warnings;
- confidence metadata.

It marks structured score source as:
`deterministic`.

Correct public framing:

> Structured score outputs are computed by versioned scoring logic from captured evidence. AI may assist with context/free-text interpretation and narrative explanation when configured; generated narrative must not fabricate or override stored structured outputs.

Do not say:
- “AI never touches scoring inputs”;
- “AI is fully air-gapped from scoring”;
- “AI determines your personality score”;
- “scientifically 98% accurate”;
- “clinical”;
- “diagnostic.”

## 4.3 Missing data

Missing = unknown.

Never present missing as:
- 0;
- 50;
- 80%;
- average;
- midpoint;
- default fit.

Use:
- `Not available`
- `Not enough evidence`
- `Not enough history`
- no plotted point.

## 4.4 Public demo data

`personalityMarketingDemo.js` contains illustrative values.

All public numerical demo fields must have one nearby field-level disclosure:

`Illustrative example`

Do not repeat disclaimers beside every number.

Do not let demo career percentages read like real personal recommendations.

## 4.5 Privacy

Only claim controls/contracts actually supported by source.

Do not invent:
- exact retention periods;
- one-click permanent purge;
- model-training policies;
- advertising/data-sale policies;
- printable export formats;
- guaranteed deletion timing;

unless verified directly in current backend/product policy.
