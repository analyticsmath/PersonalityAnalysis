# 0. Why this phase exists

Phase 1 established that the Personality Assessor problem is not a lack of styling, animation libraries, cards with better spacing, or cleaner CSS.

The failure is upstream:

> the website has repeatedly been designed as information containers instead of a single authored digital idea.

Phase 2 therefore does not ask:
- what section should come next;
- what card style should replace the old card;
- what animation can be added to an existing layout.

It asks:

> **What creative idea is native enough to Personality Assessor that it can generate the hero, motion, imagery, typography, data visualization, secondary routes, mobile choreography and product interface without falling back to a template?**

The answer locked by this phase is:

# **THE EVIDENCE IMPRINT**

# 2. Creative territories considered

A serious creative process should demonstrate that the chosen idea survived alternatives rather than simply being the first metaphor found.

## Territory A — “The Evidence Thread”

**Idea:** a continuous line connects work, questions, profile and career.

### Strengths
- easy continuity;
- strong SVG motion opportunity;
- excellent mobile translation;
- understandable metaphor.

### Rejection
Too close in spirit to MindMarket’s award-winning connecting-thread mechanism.

Even if executed differently, a persistent line as the dominant identity creates unnecessary anti-copy risk and weakens authorship.

**Status:** REJECTED AS PRIMARY CONCEPT.

A line may exist as a subordinate measurement/annotation device, but it cannot be the central brand metaphor.

It remains meaningful with motion disabled.

# 3. The one-sentence creative thesis

> **Your work leaves an imprint. Personality Assessor lifts that evidence out of the work itself, separates what it can support, and turns it into an inspectable professional profile.**

This sentence is the conceptual source of the entire site.

If a visual decision cannot plausibly be traced back to this thesis, it is probably decoration.

---

# 4. The persistent protagonist

The persistent protagonist is:

# **THE EVIDENCE IMPRINT**

It is **not one literal object** repeated identically.

It is a coherent family of physical/digital states derived from the same evidence material.

The imprint can appear as:

- an irregular crop lifted from real professional photography;
- a blueprint/document fragment;
- a contour generated from the edge of a real artifact;
- an annotation trace;
- a clipped phrase;
- a measured line;
- a set of separated signals;
- a data visualization;
- a relationship path;
- a returned artifact.

## 4.1 Four material layers

### A. Environment
Real professional photography.

This establishes where evidence came from.

### B. Material
Paper, plans, notebook edges, code/work surfaces, documents, physical project artifacts.

This makes “evidence” tangible.

### C. Trace
Sparse SVG contour/measurement/annotation behavior.

This reveals what the product is noticing.

### D. Instrument
Charts/data representations.

This reveals how evidence becomes a structured reading.

These four layers create the visual system.

Cards do not.

---

# 5. The signature behavior

The site's digital signature is:

# **THE EVIDENCE LIFT**

A meaningful part of a source environment appears to detach from that environment and become the material for the next interpretation.

The behavior has five phases:

1. **Locate** — evidence exists inside the real work.
2. **Lift** — a meaningful fragment separates from its source.
3. **Resolve** — noise drops away; the fragment becomes legible.
4. **Translate** — the same material changes into question/data/relationship.
5. **Return** — new work becomes new evidence and rejoins the system.

This behavior is the equivalent of:
- Vizcom’s sketch → render transformation;
- Zoox’s vehicle-derived geometry;
- MindMarket’s human connection system;

but is product-specific to Personality Assessor.

# 6. Static design principle

A crucial rule:

> **The page must remain excellent when all motion is disabled.**

Motion connects strong frames.

Motion cannot rescue weak frames.

Every dwell state must therefore be composed as if it were:
- a campaign still;
- an editorial spread;
- a portfolio screenshot.

The user should be able to stop scrolling anywhere important and see a finished frame.

Within the first 3–5 seconds, the visitor should understand:

- this product starts from real professional work;
- it extracts meaningful evidence from that work;
- the site itself is authored, not templated.

The hero should be strong enough that Valtum could use a screenshot of it as a portfolio cover.

## 8.2 Copy

### H1
**Your work leaves evidence.**

This remains strong.

### Support
One line only, approximately:

**See how professional context becomes questions, readings and career direction you can inspect.**

### Actions
- `Build my profile`
- `See how it works`

No eyebrow.
No metadata.
No fake score.
No decorative label.

## 8.3 Desktop visual composition

Do not use left column / right image.

Use one shared canvas.

### Typography
The H1 occupies roughly 48–55% of visual width but is allowed to cross the media boundary.

The word `evidence` should have a deliberate relationship with the evidence wall / lifted material.

### Photography
Keep the three approved images:
- architecture/workspace;
- professional/laptop context;
- evidence/plans wall.

But their roles become:

**dominant environment**  
**human proximity**  
**evidence source**

not “large photo / small photo / third photo.”

### Material imprint
A real irregular fragment is visually extracted from the plans/evidence source.

No blank CSS rectangle.

Preferred production:
- generate a local transparent PNG/WebP cutout from an approved photograph;
- or use a tight image fragment with SVG mask/clipPath;
- retain authentic texture.

The imprint should visibly originate from the source image.

## 8.4 Arrival motion

On load:

1. headline establishes;
2. environment establishes;
3. human plane enters;
4. evidence source settles;
5. a contour quietly appears around one material fragment;
6. the fragment lifts 8–18px in perceived depth and stops.

No looping hover.
No perpetual floating.

## 8.5 First scroll

The environment does not instantly disappear.

The imprint becomes the transition actor.

It moves toward the centre/next scene while the source world recedes.

This is the first proof that the site is one continuous experience.

# 9. ACT II — Work Worlds as transformations, not slides

## 9.1 Core idea

The same evidence material behaves differently depending on the work environment.

The user is not browsing a gallery.

They are observing **six modes of professional evidence**.

## 9.2 Six visual behaviors

### Build
Visual grammar:
- rectilinear construction;
- alignment;
- measured edges;
- grid/blueprint logic.

The imprint snaps into structural alignment.

### Investigate
Visual grammar:
- isolate;
- compare;
- reveal;
- inspect.

Unrelated information recedes while one trace becomes precise.

### Make
Visual grammar:
- iteration;
- repetition;
- accumulated versions.

The imprint leaves 2–3 controlled historical echoes before settling.

### Shape
Visual grammar:
- responsive contour;
- ambiguity becoming form.

The imprint morphs between two related silhouettes.

### Structure
Visual grammar:
- hierarchy;
- grouping;
- nested system.

The imprint separates into organized layers.

### Collaborate
Visual grammar:
- convergence;
- overlap;
- shared boundaries.

Two or three evidence fragments align into one shared state.

These behaviors are not decorative.
They illustrate different professional modes.

## 9.3 Media composition

One persistent environment stage.

Not six equal cards.

Not one huge 56svh generic rectangle.

Preferred desktop protagonist height:
**approximately 42–46svh**.

Surrounding visual context:
- previous world fragment;
- next world fragment;
- evidence imprint;
- current mode statement.

## 9.4 Copy

Scene title:
**Work changes the evidence.**

World copy remains extremely short.

No long detail descriptions.

## 9.5 Motion ownership

**GSAP ScrollTrigger** owns macro world transitions and scroll state.

**Anime.js** may own the local SVG/material transformation inside each settled world.

GSAP does not animate the same SVG property that Anime.js owns.

# 10. ACT III — Evidence becomes the question

This is the most important product-demonstration scene.

## 10.1 Current anti-pattern to eliminate completely

Do not show:

`document card | question form`

The user must watch one become the other.

## 10.2 Initial frame

A professional evidence field occupies the viewport.

It should look more like:
- a real document surface;
- an editorial analysis table;
- a crop from actual work;

than a UI panel.

No white card outline is required.

## 10.3 Scroll choreography

### State 1 — Source
Full context visible.

### State 2 — Noise recedes
Less relevant text/material physically loses contrast.

### State 3 — Evidence remains
One meaningful phrase/fragment stays in focus.

### State 4 — Lift
The phrase/material detaches from the document coordinate system.

### State 5 — Translate
The fragment travels toward the question origin.

The question begins from the same spatial coordinate.

### State 6 — Question established
Document is now context in the background.

### State 7 — Response controls establish
Actual task controls appear.

Then scrolling stops changing personalization.

## 10.4 Response control design

Responses are real controls, so boundaries are allowed.

But avoid card syntax.

Preferred:
- open rows;
- hairline separators;
- one circular/neutral selection marker;
- generous vertical spacing;
- no tinted fill;
- no shadow;
- no colored side edge.

## 10.5 User action

Only click/tap/keyboard selection creates the next micro-transition.

The chosen response compresses into a **qualitative evidence trace**.

Public demo result example:

**Reliability first under delivery pressure**

Not:
- +22;
- 88%;
- “feeds Conscientiousness”;
- fake confidence.

A small note can say:
`Illustrative interaction`

only once, away from the main composition.

# 11. ACT IV — Four instruments, one profile

## 11.1 Creative idea

The evidence imprint does not become one magic personality score.

It passes through **four different instruments**.

This gives us a powerful anti-card structure.

The four readings are not four cards.

They are four ways of looking at the same material.

## 11.2 Navigation

Desktop:
- short text index;
- no pills;
- no card tab bar;
- active instrument communicated by position, weight and moving line.

Mobile:
- compact direct segmented navigation or swipe + explicit labels;
- native touch;
- one instrument owns the screen.

## 11.3 Instrument A — Big Five

Visual:
- five strong horizontal lollipops;
- no container;
- generous negative space;
- labels + exact illustrative values only where explicitly marked as demo.

Motion:
- evidence trace resolves into five axes.

## 11.4 Instrument B — RIASEC

Visual:
- true radar geometry;
- ranked textual list;
- one shape, not six cards.

Motion:
- the five-axis field collapses/repositions into six radial directions.

## 11.5 Instrument C — Work Values

Visual:
- ordered vertical/horizontal hierarchy;
- physical ranking;
- bar lengths or typographic order.

Motion:
- radial structure straightens into ordered priorities.

## 11.6 Instrument D — Career Signals

Visual:
- sparse evidence-linked lollipops/relationship measures;
- selected evidence examples may appear as small material fragments.

Motion:
- hierarchy reconnects to source evidence.

## 11.7 Technology

**Anime.js SVG**
- `createDrawable()` for line construction;
- `morphTo()` for controlled shape changes;
- `createTimeline()` for instrument transformations.

Framer Motion may manage React selection/layout if easier, but do not let two systems own the same actor.

# 13. ACT VI — The return loop must actually loop

## 13.1 Core idea

Current UI says:

Gap → Work → Artifact → Evidence → Return

but visually renders five stacked rows.

The new composition must behave circularly.

## 13.2 Desktop storyboard

A professional artifact travels through one continuous loop:

1. **Gap** — a missing/weak trace is visible in the profile.
2. **Work** — environment/media expands around it.
3. **Artifact** — a real output fragment forms.
4. **Evidence** — the artifact is outlined/lifted.
5. **Return** — it physically re-enters the profile/instrument field.

The same object should be visually recognizable at stages 3–5.

## 13.3 Composition

Use:
- one dominant image/media;
- one artifact fragment;
- one profile visualization;
- a controlled curved path/sequence.

No five stacked cards.

No five equal paragraphs.

No numbered steps.

## 13.4 Mobile

Natural vertical sequence.

The artifact remains sticky for a limited distance while the context changes around it.

No long desktop pin.

# 24. Motion vocabulary

The site gets a limited vocabulary.

## Locate
Subtle contour/attention.

## Lift
Evidence separates from source.

## Resolve
Noise fades; important material becomes legible.

## Translate
One material changes representational form.

## Align
Relationships snap/settle into meaningful structure.

## Return
New evidence rejoins profile.

These six verbs replace generic:
- fade up;
- float;
- parallax;
- slide in.

For every motion, name which verb it belongs to.

If it belongs to none, remove it.
